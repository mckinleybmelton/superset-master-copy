# draft-architecture

Produce:

1. **Context** — link PRD + design decisions you rely on
2. **Components** — backend modules, frontend surfaces, data stores
3. **Boundaries / APIs** — routes, schemas, auth checks
4. **Dependency graph** — mermaid or bullet edges
5. **Risks / sequencing** — what to build first
6. **Test plan** — unit vs integration vs Playwright

Do not set `architecture_review` here — use `post-architecture-to-issue`.
